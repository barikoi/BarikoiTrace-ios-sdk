# BasicUsage example

Minimal SwiftUI app wiring `BarikoiTrace` end to end: launch-time
initialization, permission requests in the order iOS requires, sign-in,
start/stop tracking with an optional trip, the live location stream, and the
degraded-capability signal.

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
from `project.yml` — `.xcodeproj` is git-ignored, so generate it before
opening.

## Run it

1. **Credentials.** The app does not build without them:

   ```sh
   cp Examples/BasicUsage/Secrets.example.swift Examples/BasicUsage/Secrets.swift
   # fill in the real values
   ```

   `Secrets.swift` is git-ignored — the iOS equivalent of the Android
   sample's `local.properties` → `BuildConfig.API_KEY` /
   `MQTT_USERNAME` / `MQTT_PASSWORD`.

2. **Generate and open:**

   ```sh
   brew install xcodegen          # once
   cd Examples/BasicUsage
   xcodegen generate
   open BasicUsage.xcodeproj
   ```

   Order matters: a project generated before `Secrets.swift` exists will not
   reference it, and the build fails with `Cannot find 'Secrets' in scope`.
   Re-run `xcodegen generate` if that happens.

3. **Run on a real device.** The Simulator cannot exercise background
   location delivery, significant-location-change relaunch, or
   `BGTaskScheduler` — which is most of what this SDK does.

`project.yml` already declares the `Info.plist` keys and Background Modes the
SDK needs, and points the package dependency at `../../` (this checkout) rather
than the published tag, so local SDK edits show up immediately.

## What it demonstrates

**`AppDelegate.swift`** — the two launch-time calls every host app needs:
`BarikoiTrace.initialize(...)`, and `BarikoiTrace.handleLaunch(options:)`.
The second is easy to forget and has no visible symptom until it matters: an
app relaunched by iOS via significant-location-change after being killed will
not resume tracking without it. See `docs/WORK_PLAN.md` §3.

**`ContentView.swift`** — authenticate a user, request When In Use then
Always, start/stop tracking with a trip, consume the live
`AsyncStream<CLLocation>`, and surface `isBackgroundTrackingDegraded` as
visible state instead of letting background delivery quietly under-perform
with no signal to the user.

Full API reference and the required host-app setup are in the
[root README](../../README.md).
